# MemeWorld trace schema

Generated by `scripts/trace_schema_doc.py` from `backend/tracing/schema.py`; do not edit by hand. `tests/test_trace_schema.py` checks that this file is current and that every record type a mock v2 all-on day and a mock v3 co-op day emit is registered with its required fields.

## Envelope

Every line of `trace.jsonl` is one JSON record with `id`, `type`, `tick`, `time` (written by `TraceLogger.log`). `id` is `<scope>#<n>` unless the record sets its own (utterances, conversations, checkpoints); a record may also set its own `tick` (e.g. `job_start`). Run with `MEMEWORLD_TRACE_CHECK=1` to have the logger warn (never fail) on unregistered types or missing required fields.

## Layers

- **world**: the WORLD layer (world script, movement, co-op machine, binder, roster): what happened
- **agent**: the AGENT layer (perception, memory, talk, decisions): what agents noticed, kept, said and chose
- **controller**: the EXPERIMENT CONTROLLER (checkpoints, branches)
- **observer**: the OBSERVER (backend/analysis): never writes the simulation trace; no types

## Demo mode

The API without `?debug=1` applies the registry to every trace record it serves: a **hidden** type is dropped, a public type loses its **hidden fields** (dotted paths reach into nested objects). The server's generic filters (`HIDDEN_KEYS`, `HIDDEN_VALUE`, `HIDDEN_PATHS` in `backend/api/server.py`) run afterwards as a second line of defence.

## Frames (`frames.jsonl`)

One line per tick, written by `engine._frame` after the tick's trace. Fields added after v2 may be missing in older runs; readers must default them.

### `frame`

| field | meaning |
|---|---|
| `tick` | int |
| `time` | ISO datetime of the tick |
| `day` | int (1-based) |
| `label` | 'Day 2 10:15' |
| `agents` | {agent_id: agent snapshot} for every persona in the run so far (a newcomer appears from its arrival day; departed members stay, with active=false) |
| `away` | [agent ids with active=false] (departed / not on the co-op roster today); [] in v2 runs |
| `utterances` | [{id, speaker, text, listeners, conversation_id}] said this tick |
| `beats` | [{location, arena, facts: [text]}] world beats released this tick (debug adds event_id, latent_type) |
| `coop` | (v3 co-op runs only) {binder (records on), jobs} |

### `agent`

| field | meaning |
|---|---|
| `id` | agent id |
| `location` | place ('Away' when inactive) |
| `arena` | arena ('Away' when inactive) |
| `activity` | text |
| `goal` | text |
| `path` | [places traversed this tick] |
| `conversation` | conversation id or null |
| `n_memories` | int |
| `n_reflections` | int |
| `modules` | {module: state} of switched-on pressure modules |
| `active` | bool (false: departed or not on the roster) |
| `role` | (v3) am_crew \| pm_crew \| stores (a departed member keeps its last role), else null |
| `cohort` | (v3, roster on) founder \| newcomer, else null |
| `open_matters` | int: open matters still on the agent's mind (NEED; 0 when off) |
| `wordings` | int: stuck wordings heard from others held in live memories (WORDING; 0 when off) |

### `coop.binder`

| field | meaning |
|---|---|
| `binder_id` | binder-N (a wipe starts a new one) |
| `front` | {author (first name), when ('Wed 11:20'), text, revisions} or null |
| `log` | [{author, when, text}] newest first, at most 5 |
| `archived` | int: archived binders |

### `coop.jobs[]`

| field | meaning |
|---|---|
| `id` | job id (j04.2) |
| `day` | int |
| `slot` | int |
| `shift` | am \| pm |
| `operator` | agent id |
| `project` | text |
| `symptom` | the symptom fact as released (world text) |
| `attempt` | int: attempts made |
| `status` | deciding \| asking \| running \| delivered \| defer \| failed |
| `tried` | [{attempt, action, outcome}] attempts whose outcome has been released |

## API

All endpoints take `?debug=1` (Research Debug Mode) to skip demo-mode stripping. Run ids are paths under the
runs root (`<run>` or `<design>/<cell>/s<seed>`).

| endpoint | returns |
|---|---|
| `GET /api/schema` | `{envelope, layers, types: {type: {layer, since, section, description, required, optional}}, frame}`; debug adds hidden types and `hidden`, `hidden_fields`, `required_if` |
| `GET /api/runs/<id>/frames` | the frames (below), stripped in demo mode |
| `GET /api/runs/<id>/trace` | records, oldest first. Filters: `type` (comma list; `types` still works), `agent` (any record involving the agent), `tick_from` / `tick_to` (inclusive; `start` / `end` still work), `conversation` (a conversation record and every record with its `conversation_id`), `limit` (default 5000, counted after filtering). Hidden types are dropped and hidden fields removed in demo mode |
| `GET /api/runs/<id>/coop` | the co-op view of a v3 run (below); v2 runs get the same shape with empty lists and `enabled: false` |

`GET /api/runs/<id>/coop`:
